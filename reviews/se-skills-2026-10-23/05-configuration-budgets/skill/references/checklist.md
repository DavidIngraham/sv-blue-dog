# Configuration and budget checklist

Use source IDs from [sources.md](sources.md). Record a defect, consistency, evidence
gap, open decision or justified exclusion for each applicable check.

| ID | Review question | Basis |
| --- | --- | --- |
| C01 | Configuration, revision and intended use identified? | CM identification; S2 |
| C02 | Design, study, family variant and installed article distinguished? | CM; S2 7.6.7;local applicability |
| C03 | Geometry origin distinguished from current revision? | CM status accounting;local provenance |
| C04 | Hardware, software, data and procedures controlled together? | CM verification;DSE §6.1.6 |
| C05 | Proposed changes have cross-layer impact/rationale and actual disposition? | CM change control;DSE §6.1.6 |
| C06 | Historical evidence retains its original subject and revision? | CM status accounting;TA history |
| C07 | Quantity, unit, boundary, mode and exposure explicit? | SI;TM §6.3.4;local accounting |
| C08 | Limits, allocations, estimates and accepted measurements distinguished? | TM §3.2.5;DSE §6.1.3 |
| C09 | Required functions and support equipment covered? | TM §6.3.3;local completeness |
| C10 | Parent/child and replacement aggregation counted once? | TM §6.3.3 aggregation;local application |
| C11 | Average demand, duty, coincidence and peak capability separated? | TM measure definition;local electrical accounting |
| C12 | Storage, conversion losses and protected reserves reconciled? | SI quantity meaning;local energy accounting |
| C13 | Main/recovery/fault modes use the correct accounts? | CM applicability;local allocation |
| C14 | Mass, CG, power, exposure and timing coupled where consequential? | TM §6.3.3;local physical analysis |
| C15 | Uncertainty allowance separated from remaining margin? | DSE §6.1.3;TA |
| C16 | Unknown entries remain unset and coverage open? | CM verification;local missing-data rule |
| C17 | Measurement owner, collection basis and update trigger explicit? | TM §6.4;TA |
| C18 | Configuration mismatch and stale evidence rejected? | CM verification;local native controls |
| C19 | Native bindings and unit/aggregation boundaries tested? | S2;local regression practice |
| C20 | Accounting readiness kept separate from physical acceptance? | CM product verification;local evidence interpretation |

Select measures because they answer consequential questions. Do not populate
unused ledgers or fabricate growth factors to make a report look complete.
