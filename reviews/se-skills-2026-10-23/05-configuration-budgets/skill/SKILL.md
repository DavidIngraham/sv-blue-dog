# Configuration and budget management

Establish which product description and resource account each claim concerns.
Read the [sourced checklist](references/checklist.md) and [source register](references/sources.md).
Use the project's native model, calculation and evidence facilities.

## Workflow

1. Identify the engineering question and authoritative configuration: mission,
   complete design, capability assumptions, candidate assembly, software/data,
   procedure and actual article where applicable. Distinguish a numerical starting
   geometry, a study candidate, a product-family variant and an installed instance.
2. Inventory native configuration references, source revisions/fingerprints,
   alternatives, resource accounts, allocations, analysis subjects and evidence.
   A persistent name is not an immutable revision; an archived numerical origin is
   not the current configuration revision. Preserve historical subjects and results.
3. For each relevant budget establish quantity/unit, physical/accounting boundary,
   operating mode/exposure, owner, source, aggregation/replacement rules and maturity.
   Distinguish limits, allocations, estimates, uncertainty allowances and remaining
   margin. Missing loads or unknown capability are not zero.
4. Audit complete functional coverage and cross-couplings. Include acquisition,
   processing, conversion, controls, storage, communications and support hardware
   where applicable. Review power peaks separately from average energy; simultaneous
   demand, duty and fault/recovery modes need their own evidence. Avoid counting
   a parent allowance plus its children, or a replaced component twice.
5. Assess a proposed change across requirements, interfaces, safety, performance,
   mass/CG, energy, timing, analyses and verification. Implement authorized
   corrections, preserving owner policy and original evidence. Follow actual
   project change authority where it applies; this skill creates no blanket
   approval gate for reversible model work.
6. Reconcile native reports, actual configuration status and affected documentation.
   Verify changed bindings/rollups, missing input, unit boundaries, double counting,
   stale evidence and configuration substitution. Preserve source fingerprints and
   a reproducible stage record; distinguish accounting closure from qualification.

## Interpretation

A balanced allocation is not a measured bill of materials. A battery's nameplate,
usable capacity, departure energy, withdrawal and reserve describe different
accounts; define them before combining quantities. Stored-energy adequacy does
not establish peak electrical capability or safe recovery.

Current best estimate, contingency and margin must follow the adopted budget
convention. Agency example percentages are not universal defaults. Keep incomplete
coverage and unsupported limits explicit instead of inventing numerical values.
A supplied review flag organizes evidence; it does not inspect records, grant a
waiver, approve hardware or accept a configuration on someone's behalf.
