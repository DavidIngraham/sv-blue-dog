# Sourced decision-quality checklist

Record scope, evidence and disposition for each applicable check. Missing data can
justify another experiment or an open decision; it cannot justify fabricated scores.

| ID | Check / evidence expected | Basis |
| --- | --- | --- |
| D01 | State the decision question and intended outcome. | N6.8.1.1;D6.1.2 |
| D02 | Identify mission, configuration, lifecycle and current/future scope. | N6.8.1;C6.5 |
| D03 | Identify responsible role and consequential cost/risk/schedule drivers. | N6.8.1.1;D6.1.2 |
| D04 | Distinguish baseline, hardware selection, policy and acceptance decisions. | N6.8.1.3;local scope control |
| D05 | Inventory plausible alternatives and continuation/no-change where meaningful. | N6.8.1.2.2 |
| D06 | Keep independent design axes and incomplete contenders visible. | N6.8.1.2.2/.5;local modeling control |
| D07 | Trace mandatory criteria to applicable actual obligations. | N6.8.1.2.1;S7.23 |
| D08 | Separate comparative preferences and unaccepted study objectives from gates. | N6.8.1.2.1;D6.1.2 |
| D09 | Define evidence states; unknown is neither failure nor passing evidence. | A4.3.1;local evidence control |
| D10 | Use common mission cases, configuration boundaries and comparable evidence. | N6.8.1.2.4;I6.3 |
| D11 | Identify scale, units, direction, normalization and data sources. | N6.8.1.2.1/.4;I6.3 |
| D12 | Assess safety, performance, resources, construction, lifecycle cost and schedule when material. | N6.8.1.2.1;D6.1.2 |
| D13 | Select a proportionate method; justify preferences/weights if used. | N6.8.1.2.3/.4 |
| D14 | Do not compensate mandatory violations with aggregate benefit. | N6.8.1.2.1;local native preflight control |
| D15 | Report uncertainty, correlation, domain and assumption sensitivity. | N6.8.1.2.4/.5;A4.3.3/.5 |
| D16 | Preserve ties/close contenders and explain ranking reversals/dominance. | N6.8.1.2.5;S9.4.5 |
| D17 | Identify what further evidence could change the decision and its value. | N6.8.1;N6.8.1.2.4/.5 |
| D18 | Separate analytical result, recommendation and actual decision/rationale. | N6.8.1.3;S7.23.3 |
| D19 | Record actual authority/date/configuration and implementation evidence when known. | N6.8.1.3;C6.5;local record control |
| D20 | Define reopening triggers and affected requirements, interfaces, budgets, risks and V&V. | N6.8.1.2.6/.7;C6.5 |
| D21 | Verify missing input, gate failures, provisional criteria, ties and sensitivity. | S7.23.3;A4.3;local regression control |
| D22 | Reconcile model, report and open questions without rewriting history. | N6.8.1.2.7;C6.5 |

Probes: unknown rig evidence retains development standing; failed mandatory
criterion blocks eligibility; failed provisional study target is reported without
becoming a hidden mandatory veto; numerical baseline does not become rig selection;
a tie's first native result does not become a unique preference; missing scores
are not zero; changed operating assumptions reopen a disposition.
